# Discord Hava Durumu ve Bilgi Botu

## Proje Hakkında
Bu proje, Discord üzerinde çalışan ve kullanıcılara ilginç bilgiler, hava durumu ve kıyafet önerileri sunan bir bottur.

## Özellikler
- **!start:** Kullanıcıyı karşılar.
- **!fact:** API üzerinden rastgele ilginç bilgi getirir.
- **!hava:** Girilen şehrin hava durumunu öğrenir.
- **Kıyafet Önerisi:** Hava sıcaklığına ve hava durumuna göre kıyafet önerir.
- **Seslendirme:** Gönderilen bilgileri pyttsx3 ile seslendirir.

## Kullanılan Teknolojiler
- Python
- Discord.py
- Requests
- Pyttsx3
- Useless Facts API
- Open-Meteo API

## Kurulum

Gerekli kütüphaneleri yükleyin:

```bash
pip install discord.py requests pyttsx3
```

## Kullanım
1. Discord Developer Portal üzerinden bot oluşturun.
2. Bot tokeninizi koda ekleyin.
3. Python dosyasını çalıştırın.
4. Discord sunucusunda komutları kullanın.

## Komutlar
- `!start`
- `!fact`
- `!hava`

## Geliştirici
Python ile geliştirilmiştir.
